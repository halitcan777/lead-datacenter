# Калькулятор дата-центра — три прототипа

**Открыть:** https://permkvadrat59-star.github.io/datacenter-calculator/

Три варианта интерфейса одного расчёта. Все три рабочие — цифры считаются в браузере по единому ядру, а не подставляются из готовой таблицы.

| Вариант | Формат | Что считает |
|---|---|---|
| **А. Экспресс** | Встроенный блок внутри страницы, три поля | CAPEX, количество стоек, PUE, ориентир окупаемости |
| **Б. Мастер** | Отдельная страница, четыре шага | + структура CAPEX по семи статьям, OPEX, срок окупаемости |
| **В. Инвест-модель** | Самостоятельный инструмент, десять параметров | + P&L на 10 лет, IRR, график накопленного потока, режим «ЦОД для себя» |

## Модель расчёта

Удельный CAPEX 620–950 тыс. ₽ за кВт IT-мощности в зависимости от уровня надёжности, с региональным коэффициентом 0,86–1,00 и поправкой 0,83 на реконструкцию вместо нового строительства. PUE 1,40–1,60 с климатической поправкой. OPEX — электроэнергия по тарифу и загрузке, персонал, обслуживание инженерных систем, прочее. Выход на загрузку 30 % → 60 % → 80 % → целевая.

Срок окупаемости простой, по EBITDA, без учёта налогов, амортизации и стоимости финансирования.

Полный список коэффициентов — в конце самой страницы. Они вынесены в отдельный слой и заменяются на любые другие без переписывания расчёта.

## Технически

Одна самодостаточная HTML-страница без сборки и зависимостей. Работает на телефоне, поддерживает светлую и тёмную тему.
